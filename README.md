# RAG-NAROK

Code and experimental artifacts accompanying the paper:

**RAG-NAROK: Retrieval-Aware Knowledge Corpus Poisoning in RAG with Source-specific Refutation**
Abdullahil Kafi and Alvi Ataur Khalil
TITANS Lab, Computer Science, Southern Illinois University
arXiv:2609.25469

RAG-NAROK is a black-box, context-adaptive attack framework against retrieval-augmented generation (RAG) systems. It performs reconnaissance on a target retriever, then generates Anchor-Specific Refutation documents that name and devalue legitimate retrieved sources to degrade the quality of generated answers.

## Contents

- `ragnarok_experiments_{v1,v2}.ipynb` — experiment notebooks.
- `CyberSec-Dataset_escaped.jsonl` — first 10,000 lines of the cybersecurity Q&A corpus (truncated due to size limits) used to build the retrieval knowledge base.
- `cfr_corpus_2025/` — Code of Federal Regulations (legal domain) text corpus, split by volume.
- `A Tale of Demand and Supply for Central Bank Reserves.pdf`, `Anchored to the Dot Plot: Central Bank Projections and Interest Rate Expectations.pdf` — the two finance papers used as the finance-domain corpus.
- Other PDFs — plots generated by the notebooks.

## Setup

Experiments were run against a local LLM served via [Ollama](https://ollama.com) (OpenAI-compatible API at `http://127.0.0.1:11434/v1`, model `mannix/llama3-8b-ablitered-v3`). Key Python dependencies include:

```
langchain, langchain-community, langchain-huggingface, langchain-text-splitters
sentence-transformers, faiss, openai, pydantic
numpy, pandas, scikit-learn, umap-learn, textstat
matplotlib, seaborn
```
